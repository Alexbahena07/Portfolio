# Alex Bahena — Portfolio

Personal portfolio website, hosted on GitHub Pages.

🔗 [Live Site](https://alexbahena07.github.io/Portfolio/)

## Built With

- HTML5 / CSS3 with light and dark themes (CSS custom properties)
- Vanilla JavaScript, with no frameworks or build step
- Self-hosted Poppins and Lora webfonts, Font Awesome icons
- [FormSubmit](https://formsubmit.co/) for the contact form

## Featured Projects

- **COLAB Clubhouse** — Production career platform (Next.js, TypeScript, Prisma, PostgreSQL, Stripe, Claude API) · [Live](https://www.colabconnects.app/)
- **Cruz Installations & Remodeling** — Client marketing site · [Live](https://cruzinstallations.com/) · [Code](https://github.com/Alexbahena07/CruzInstallations)
- **Instagram Clone** — Flask REST API + React feed · [Code](https://github.com/Alexbahena07/InstagramClone)

## Running Locally

There's no build step. Serve the folder and open it in a browser:

```bash
python3 -m http.server 8000
```
